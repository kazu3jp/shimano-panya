# しまのぱんやさん

パンの在庫をカメラで読み取り、アプリで確認できる作品。

![しまのぱんやさん](img/panya_logo.png)

## 作品概要

パンの在庫をカメラで読み取り、アプリで確認できる作品です。
パンの在庫をカメラで読み取ることで、リアルタイムで在庫状況を把握できます。
アプリでは、在庫の種類や数量を確認できます。
